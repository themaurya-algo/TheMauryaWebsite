After approval: create your Delta API key and secret
  1. Sign in to Delta Exchange India and open Profile → API Keys.
  2. Select Create New Key and name it Trading with TheMaurya.
  3. Enable only Read Data and Trading.
  4. Add the authorized connection IP displayed in your private TheMaurya dashboard. Delta requires an IP whitelist for a Trading key.
  5. Create the key, complete OTP or 2FA, and copy both the API key and secret immediately. Delta may show the secret only once.
  6. Enter both credentials only in the secure connection panel inside your approved dashboard, then select Connect & Verify.

Security: never send your API secret through email, Telegram or WhatsApp. Never enable withdrawal or transfer access. You can revoke the key from Delta at any time.

05 / SAFETY & CLARITY

Know what the technology
does — and doesn't do.

Automated does not mean risk-free.

Crypto derivatives can be highly volatile. Leverage, liquidation, slippage, fees, gaps, connectivity and software failures can cause substantial losses. Profit targets are not guaranteed.

Read full notices when applying ↗
Does signing up start trading?

No. Registration and Master approval grant account access only. Live trading requires separate verification and authorization.

No. BTC is shown as a future strategy, not a live or assignable offering.

Does the public site show my positions?

No. Market index quotes are public. Your account and positions remain inside your authenticated dashboard.

Are returns guaranteed?

No. There are no guaranteed returns, and losses can include your entire committed capital.
